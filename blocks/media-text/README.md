# Beeld + tekst (nieuw type `media_text`)

**Doel:** afbeelding naast tekst, met keuze links/rechts, verhouding en beeldstijl. Meerdere onder elkaar met wisselende kant = het klassieke lange-pagina-patroon.

**Content (per markt):** eyebrow, title, body (markdown), cta_label/href, image_alt.
**Data:** image_url (zelfde upload als banner), media_side, ratio (1:1|2:3|3:2), media_style (rounded|card|plain), heading_level (h2|h3), align (center|top), section.*.

**Categorie:** Content & Editorial. **Toegestaan:** alle groepen. **Max:** onbeperkt (role-pool).

**Later (niet nu):** `media_type: image|video` en een tweede knop.
