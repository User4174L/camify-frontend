# CTA-band (nieuw type `cta_band`)

**Doel:** één oproep + 1–2 knoppen, tussen tekstblokken of als afsluiter. Herbruikbaar via presets ("Verkoop je camera", "Nieuwsbrief", "Kom langs in de showroom").

**Content (per markt):** title, subtitle, primary_label/href, secondary_label/href. Links per markt zodat elke taal naar de eigen URL kan.
**Data:** variant (brand|inverse|light), align (left|center), compact (bool), section.*.

**Categorie in de picker:** Capture & Convert. **Toegestaan:** alle groepen. **Max per pagina:** onbeperkt (role-pool `cta_band`, `cta_band_1`, …).
